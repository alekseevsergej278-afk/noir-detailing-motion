# NOIR / Свет показывает разницу

Основная идея: детейлинг виден в том, как поверхность отражает свет. Сайт ведёт человека через внимание, осмотр лака, выбор ухода, сохранение результата и финальную проверку.

## Что взято из исследования

- Glosswerk: демонстрировать свойства услуги через взаимодействие. Новый NOIR использует собственную реализацию и графику осмотра лака, а не код или ассеты референса.
- Prestige / Made Agency: связать движение с автомобильной формой. Для NOIR это линия отражения, горизонтальная световая полоса и последовательное проявление текста.
- Urbanity: давать автомобилю и поверхности значительную часть экранного пространства.

## Собственный язык

Один графитовый фон #101211 на всей странице. Освещённая поверхность выступает из него. Узкий Oswald вместо прежней пары обычного гротеска и курсива. Сигнальный светлый акцент #dfed9b используется для действия, состояния и положения света.

Два студийных изображения созданы специально для этой концепции через встроенный ImageGen. Canvas наносит воспроизводимые смоделированные микроцарапины поверх чистого макрокадра. Движение мыши или доступного ползунка меняет свет. Кнопка «После коррекции» плавно убирает дефекты, сохраняя положение луча. Демонстрационная природа эффекта указана рядом.

Все состояния доступны с клавиатуры. На телефонах движение луча управляется ползунком, не мешающим вертикальному скроллу. При reduced motion смена состояния происходит без пространственной анимации.

Другие движения: проявление строк hero, боковое раскрытие фотографий, последовательная подсветка фразы при скролле, смена изображения выбранной услуги, прогресс процесса, parallax и hover кнопок. Эффекты не требуют 3D и внешних анимационных библиотек.
