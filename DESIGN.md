# NOIR visual system

## Direction
Persuade: premium automotive editorial, as specified by the user. Full-width moving-car photography, open typographic fields, service index and asymmetric gallery. An independent 2D identity, not a reduced 3D site. Code-led implementation anchored in the explicit brief.

## Tokens
- Background #111210; section surface #191a17; contact surface #24271f.
- Foreground #f1eee6; secondary #aeafa5; champagne #d1c2a4; divider #373932.
- Manrope 400–800, locally hosted. Georgia italic only for expressive words.
- Body 15px / 1.7; reading copy 12–15px; display 34–96px; mobile hero 32–62px.
- Desktop section gutters 6.25%; mobile 6%; vertical section rhythm 116px / 72px.
- Square geometry, hairline dividers, no service card grid.

## Components and behavior
Champagne primary CTA, outlined secondary CTA, underlined editorial links. Native service disclosures, dialog image viewer, full-screen mobile navigation. Single arrow and icon stroke system. Focus rings and selection use champagne.

## Motion
Ease cubic-bezier(.16,1,.3,1). Hero line masks; image clip reveals; opacity/transform text reveals; staggered principles. Photo displacement 24px desktop / 10px mobile. Passive scroll listener schedules requestAnimationFrame; geometry is processed only for photos in view. Reduced-motion preference removes animation and scroll smoothing.

## Content truth
Prices, address and studio identity are demonstrative. Contacts remain unconfigured until the owner supplies real values. No testimonials, invented numerical proof, forms or trackers.
