# NOIR Detailing Motion

Самостоятельный премиальный 2D-лендинг на HTML, CSS и JavaScript. Без сборки, npm-зависимостей, 3D, аналитики и форм.

## Запуск

Из папки проекта:

```powershell
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173 в браузере. Можно также открыть `dist/index.html` напрямую. Для публикации загрузите содержимое `dist` на любой статический хостинг с HTTPS.

## Структура

```text
dist/
  index.html       — контент и структура страницы
  style.css        — дизайн, адаптивность, анимации
  app.js           — меню, услуги, галерея, scroll progress и parallax
  motion.js        — маски заголовков и анимации овальных кнопок
  inspection.js    — двухмерный свет, дефекты и ползунок
  config.js        — контакты, адрес, часы работы, услуги и цены
  assets/          — локальные фотографии, шрифты, favicon
qa/                — скриншоты и отчёт проверки
PRODUCT.md         — продуктовый контекст
DESIGN.md          — визуальная система
ASSETS.md          — происхождение материалов
```

## Как адаптировать под клиента

1. Заполните `phone`, `whatsapp`, `telegram` в `dist/config.js`. Пустые значения показывают уведомление о демонстрационном режиме. Телефон задаётся с кодом страны; WhatsApp — международный номер; Telegram — имя пользователя.
2. Там же измените адрес, расписание, описания, цены и сроки услуг.
3. В `index.html` замените название, тексты и фотографии; актуализируйте alt-описания. После подключения настоящих контактов замените текст «Контакты студии пока не подключены». Снимите демонстрационные пометки только после проверки реальных данных.
4. Цвета находятся в CSS-переменных в начале `style.css`. Шрифты Manrope и Oswald хранятся локально.
5. Фотографии являются редакционной подборкой, а не кейсами студии. Для реального клиента замените их собственными работами с разрешением на публикацию.

## Концепция и интерактив

«Свет показывает разницу». Весь сайт использует один фон #101211. Собственный сценарий и связь с референсами описаны в CONCEPT.md.

Инспекционный свет: ведите мышью по кадру или двигайте ползунок. Переключайте «До коррекции» / «После коррекции». Царапины смоделированы Canvas 2D и не являются реальным кейсом. Ползунок поддерживает стрелки, Home и End. На телефонах он управляет светом, сохраняя нормальный вертикальный скролл.

Другие эффекты: строки hero, боковое раскрытие кадров, подсветка текста по мере чтения, смена изображения услуги, линия прогресса процесса, parallax и hover. Скролл нативный. prefers-reduced-motion отключает пространственные движения и плавный скролл, смена поверхности становится мгновенной.

Меню поддерживает Escape и ограничение фокуса. Галерея использует нативный dialog с Escape и возвратом фокуса. Услуги — нативные details/summary.

Студийные фото atelier.png и paint.png созданы встроенным ImageGen для проекта; точные промпты сохранены в соседних .png.json. О происхождении фото и шрифтов см. ASSETS.md. Это визуальная концепция, не портфолио студии.

Контактные сообщения сайт самостоятельно не отправляет. После настройки config.js кнопки открывают сервис переписки или приложение звонков.

Проверки и скриншоты новой версии находятся в qa/REPORT.md и qa/v2-*.jpg. Измерение Lighthouse и тесты на реальных устройствах не выполнялись.

## Обновление анимаций и управления

Референсы и принципы записаны в MOTION.md. Кнопки действий имеют форму капсулы. Заголовки раскрываются по словам через маски, кнопки получают перекат подписи и мягкое притяжение на устройствах с мышью. Мобильные цели нажатия остаются неподвижными. В инспекции свет движется по X/Y, а нативный ползунок с круглой ручкой управляет положением по горизонтали. Царапины проявляются только в мягкой области луча. Этапы пронумерованы 1–4.
