# NOIR Detailing Motion

Лендинг NOIR. Страница размещается на статическом хостинге, а круговая галерея и анимации собираются из React, TypeScript, Tailwind CSS и Motion.

## Запуск

Из папки проекта:

```powershell
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173 в браузере. Для публикации загрузите содержимое `dist` на любой статический хостинг с HTTPS.


## Настройка и сборка компонентов

В существующем проекте конфигурация уже есть. Установите Node.js 22.12+ и pnpm 11, затем выполните:

```powershell
pnpm install --frozen-lockfile
pnpm build
```

Сборка проверяет TypeScript и обновляет `dist/assets/gallery`. Компонент лежит в `components/ui/circular-gallery.tsx`. Алиас `@/components/ui` совпадает в Vite, TypeScript и `components.json`. Эта папка даёт CLI shadcn единое место для добавления компонентов и сохраняет их стандартные пути импорта. Файл стилей для CLI задан как `src/gallery.css`.

Для нового проекта можно выполнить `pnpm dlx shadcn@latest init -t vite` и выбрать шаблон React с TypeScript. Если React + TypeScript уже созданы через Vite, добавьте `tailwindcss` и `@tailwindcss/vite`, подключите плагин в Vite, настройте алиас `@/` в Vite и TypeScript и запустите `pnpm dlx shadcn@latest init`. Затем поместите компонент в папку, указанную в `aliases.ui`, и подключите Motion и Lucide через `pnpm add motion lucide-react`. [Руководство shadcn для Vite](https://ui.shadcn.com/docs/installation/vite)

## Как адаптировать под клиента

1. Заполните `phone`, `whatsapp`, `telegram` в `dist/config.js`. Пустые значения показывают уведомление о демонстрационном режиме. Телефон задаётся с кодом страны; WhatsApp — международный номер; Telegram — имя пользователя.
2. Там же измените адрес, расписание, описания, цены и сроки услуг.
3. В `dist/index.html` замените название и тексты, а в `src/gallery.tsx` задайте свои фотографии, подписи и alt-описания. Обновите резервные кадры в `dist/index.html` и выполните сборку. После подключения настоящих контактов замените текст «Контакты студии пока не подключены». Снимите демонстрационные пометки только после проверки реальных данных.
4. Цвета находятся в CSS-переменных в начале `style.css`. Шрифты Onest и Cormorant Garamond хранятся локально.
5. Фотографии являются редакционной подборкой, а не кейсами студии. Для реального клиента замените их собственными работами с разрешением на публикацию.

## Концепция и интерактив

«Свет показывает разницу». Весь сайт использует один фон #101211. Собственный сценарий и связь с референсами описаны в CONCEPT.md.

Инспекционный свет движется за мышью или по касанию кадра. Круглый захват Two-Up внутри фотографии двигает границу сравнения. Захват поддерживает стрелки, Home и End. Царапины смоделированы в Canvas 2D.

Motion управляет индикатором прокрутки, поворотом галереи, появлением текста и откликом кнопок. При системном уменьшении движения галерея меняет кадры без пространственного поворота.

Меню поддерживает Escape и ограничение фокуса. Галерея вращается сама и реагирует на прокрутку страницы. Кадры также можно листать жестом вбок и стрелками клавиатуры. Фотография открывается в нативном dialog с Escape и возвратом фокуса. Услуги — нативные details/summary.

Студийные фото atelier.png и paint.png созданы встроенным ImageGen для проекта; точные промпты сохранены в соседних .png.json. О происхождении фото и шрифтов см. ASSETS.md. Это визуальная концепция, не портфолио студии.

Контактные сообщения сайт самостоятельно не отправляет. После настройки config.js кнопки открывают сервис переписки или приложение звонков.

Проверки и скриншоты новой версии находятся в qa/REPORT.md и qa/v2-*.jpg. Измерение Lighthouse и тесты на реальных устройствах не выполнялись.
